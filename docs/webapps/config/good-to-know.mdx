# Good to know

## manifest.json

If a WebApp has been created with a specific ID, its appData is associated with that ID. Changing the WebApp ID may cause the appData to become inaccessible, as the data linkage is based on the original ID.

Before changing the ID of a WebApp, make sure to consider the potential impact on existing appData, as important data may be lost or disconnected from the application.
